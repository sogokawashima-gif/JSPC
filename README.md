# 深夜監視記録

事故物件に設置された監視カメラの映像を見張り、**「あってはならないもの」** を見つけて報告する、ブラウザで遊べる異変探しホラーゲームです。

- インストール不要。`index.html` 1ファイルだけで動きます。
- 映像はすべてプログラムで描画し、音は Web Audio API で合成しています。画像・音声ファイルは使っていません。

## 遊び方

| 項目 | 内容 |
| --- | --- |
| 勤務時間 | 深夜0時〜朝5時（現実の約5分） |
| 目的 | 6台のカメラを切り替え、異常を見つけたらその場所をクリック（タップ）して報告する |
| 業務失敗 | 未報告の異常が3件たまったまま警告時間を過ぎる／誤報告が上限に達する |
| 暗視モード | 暗視でしか見えない異常があります |
| 給与 | 時給 ¥1,500（特別手当付きは＋¥1,000）。リザルトの「見逃しポイント」は給与で開放できます |

### 難易度

- **通常業務**：開始前に3分間の確認時間があります（異常は起きません）。誤報告は5回まで。
- **特別手当付き**：すぐに業務開始。細かい異変が多めで、誤報告は3回まで。

### 操作

| 操作 | PC | スマホ |
| --- | --- | --- |
| 異常を報告 | 左クリック | タップ |
| 暗視モード | 右クリック／`N` | 右下の目のボタン |
| カメラ切替 | `←` `→`／`1`〜`6` | 画面左右の矢印 |
| カメラ一覧 | `M` | 右上のメニュー |
| 一時停止 | `Esc`／右上の一時停止ボタン | 右上の一時停止ボタン |

> 音が出ます。ヘッドホン推奨です。

### スマホで遊ぶとき

- **横向き**で遊んでください。縦向きにすると自動で一時停止し、案内が表示されます。
- 対応端末では、開始時に全画面表示・横向き固定になります（iPhone の Safari は全画面非対応のため、横向きにするだけでOKです）。
- 別のアプリに切り替えると自動で一時停止します。
- スマホでは動作を軽くするため、映像の色ずれ・ノイズ効果を控えめにしています。
- 心臓が止まるような演出では、対応端末で振動します。

## GitHub Pages で公開する手順

### 方法A：ブラウザだけで公開する（かんたん）

1. GitHub で新しいリポジトリを作成します（例：`midnight-watch`、**Public**）。
2. リポジトリ画面の **Add file → Upload files** から、このフォルダの `index.html`・`README.md`・`.nojekyll` をアップロードして **Commit changes** を押します。
   - `.nojekyll` は隠しファイルのため、エクスプローラーで表示されない場合は「隠しファイルを表示」をオンにしてください。
3. **Settings → Pages** を開き、**Source** を `Deploy from a branch`、**Branch** を `main` ／ `/ (root)` にして **Save** を押します。
4. 1〜2分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります。スマホからもこのURLを開くだけで遊べます。

### 方法B：git コマンドで公開する

```bash
git init
git add index.html README.md .nojekyll .gitignore
git commit -m "深夜監視記録 初回公開"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
git push -u origin main
```

その後、方法Aの手順3〜4と同じ手順で GitHub Pages を有効にします。

### 更新するとき

`index.html` を上書きしてコミット（方法Aならアップロードし直し）すると、数分で公開ページにも反映されます。

## ファイル構成

```
index.html   ゲーム本体（HTML / CSS / JavaScript をすべて含む）
README.md    この説明
.nojekyll    GitHub Pages の Jekyll 変換を無効にする空ファイル
.gitignore   公開しない一時ファイルの除外設定
```

## 補足

- 所持金と開放状況はブラウザの保存領域（localStorage）に保存されます。端末やブラウザが変わると引き継がれません。
- 登場する物件・人物・団体はすべて架空のものです。
